# personal-copilot

A NestJS + Expo scaffold: Gateway, Auth Service (Postgres-backed login/JWT), a Telegram channel any
app user can link their chat to (send/receive, generic plumbing), full OTel observability, and a
frontend with working login/register — the shared infrastructure this project started with, kept
as the base for whatever feature comes next. No product feature is built on top of it yet.

See [CLAUDE.md](CLAUDE.md) for architecture, setup, and how this repo is organized —
[docs/specs/](docs/specs/) for the service/event contracts.
